# Test Responses & Execution Logs (`responses/`)

This directory contains the detailed execution outputs and diagnostic logs generated by the automated test runner ([run_tests.py](file:///d:/Downloads/assembler_new/run_tests.py)).

---

## Files in this Directory

### 1. `all_tests_summary.txt`
The master execution summary across all 100 test cases:
* **Summary Score**: 100/100 (100.0% Pass rate — 60/60 valid tests passed, 40/40 error tests correctly caught).
* **Master Results Table**: Includes Test ID, filename, test type (`VALID` vs `ERROR`), pass/fail status, the handling pipeline stage / worklet, and specific notes or error messages.
* **Full Worklet Outputs**: Comprehensive concatenated output for all 100 tests.

### 2. `test_XXX_response.txt` (test_001 to test_100)
Individual per-test reports capturing every phase of execution:
* **Header**: Test ID, descriptive title, category, and overall outcome.
* **Source Code**: The exact assembly input being tested.
* **Worklet 1 Output (`--w1`)**:
  - Parsed Program IR (`w2::Instruction` array).
  - Discovered labels and dense label IDs (`extId`, `endLabel`).
  - Recorded symbol references (`refs`).
* **Worklet 2 Output (`--w2`)**:
  - Machine code disassembly listing with byte offsets and hexadecimal byte sequences.
* **Worklet 3 & Full Pipeline Output**:
  - ELF Header details (`Elf32_Ehdr`).
  - Section Headers table (`.text`, `.data`, `.bss`, `.symtab`, `.strtab`, `.rel.text`).
  - Relocation dump (`R_386_32`, `R_386_PC32`).
  - Self-check validation status.

---

## How to Regenerate These Reports

To re-run the entire test suite and refresh all files in this directory:

```bash
python run_tests.py
```
